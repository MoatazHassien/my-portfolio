About

I'm a Computer and Data Science student at Alexandria University, working toward a career in Data Engineering. My interest lies in how raw, messy data becomes something reliable and useful — the pipelines, structures, and logic that move information from a source to a system someone can actually query and trust.

Day to day, that means practicing with Python for data processing and cleaning, learning SQL and relational database design, and studying the concepts behind ETL and data warehousing. I like breaking a messy dataset down, figuring out what's wrong with it, and rebuilding it into something structured.

I'm early in this path — a student, not a working professional — and I'm using coursework and independent projects to turn that interest into practical, demonstrable skill.

What I'm focused on

  • Data processing & cleaning
  • Python for data work
  • SQL & relational databases
  • ETL concepts
  • Data pipeline design
  • Problem solving through projects
